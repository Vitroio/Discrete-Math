This is the set of all elements that are both elements of \(A\) and not elements of \(B\text{.}\) What have we done? We’ve started with \(A\) and removed all of the elements that were in \(B\text{.}\) Another way to write this is the set difference:
\begin{equation*} A \cap \bar B = A \setminus B\text{.} \end{equation*}
